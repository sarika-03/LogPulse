# Contributing to LogPulse

Thank you for contributing to LogPulse! We welcome contributions that improve the project, fix bugs, enhance documentation, or add new features.

---

# Tech Stack

LogPulse uses the following technologies:

## Frontend
- React
- TypeScript
- Vite
- TailwindCSS
- Recharts
- React Query

## Backend
- Go (Golang)

## DevOps & Infrastructure
- Docker
- Prometheus
- Grafana
- Helm

---

# Getting Started

## Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm
- Go 1.22+
- Git

---

# Project Setup

## 1. Fork the Repository

Click the **Fork** button on GitHub and clone your fork locally.

```bash
git clone https://github.com/your-username/LogPulse.git
cd LogPulse
```
